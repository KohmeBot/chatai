# ChatAI 后台 UI 设计规范

适用范围：`chatai/monitor` 下所有后台页面、浮层、表单及交互。后续 Codex 修改应先遵循本规范，再扩展组件。视觉方向是接近 iOS 26 液态玻璃的轻盈层次、克制高光和缓慢收束的运动；这是项目自身的 Web 设计语言，不依赖 Apple 专有组件。

## 1. 材质与层级

- 延续现有浅色冰蓝、淡紫、薄荷背景与深色石墨基调。所有颜色引用 `glass.css` 的语义变量；组件内不硬编码仅适合浅色的背景或文本颜色。
- `--panel` 是浮层基底，`--surface` 是内层玻璃，`--code` 是低强调输入区域，`--selected` 是范围与选中背景。
- 使用 `--rim` 表达上沿反光，`--glass-edge` 表达下沿，`--shadow` 表达柔和投影。模糊是层次辅助，不能代替足够的文字对比度。
- 大面积玻璃只放在承载层；不要对每个日期、标签或文本叠加 backdrop-filter。弹窗沿用 `.memory-dialog` / `.glass-dialog` 的渐变、40px 模糊与圆角。
- 主色 `--accent-fill` / `--on-accent` 只用于主要确认动作及重要选中端点；范围内部用淡色连续带，避免整片高饱和色。
- 无 backdrop-filter 或减少透明度时使用现有实色降级规则，新容器必须加入相同降级覆盖。

## 2. 图标与文字

- 图标统一使用 `ConsoleControls.icon()`，24×24 viewBox、1.65 描边、圆角端点。新增图标加入共享 paths，不用 emoji 或不同图标库混搭。
- 关闭、确认、刷新、翻页、自定义日期等明确动作使用 `iconButton()`；保留准确 `aria-label` 和 `title`，点击热区通常至少 44×44px。
- 今天 / 近三天 / 近一周需要区分范围，保留短文字搭配日历图标。不要为了无文字而让三个按钮出现完全相同且无法辨认的图案。
- 日期、错误、字段标签、用户内容必须可读。辅助说明只放一处，保持简短；不要把实现术语暴露给产品用户。
- 字体沿用系统字体栈；数值和日期使用 tabular-nums。层级主要依靠字号、留白和颜色，不依靠到处加粗。

## 3. 组件复用

| 场景 | 组件 / API | 要求 |
| --- | --- | --- |
| 分段选择 | `.status-segments` + `ConsoleControls.mountSegments()` | 复用可拖动的 `.glass-lens`；以 aria-pressed 表达选中，禁止额外叠加选中色块 |
| 图标动作 | `ConsoleControls.iconButton()` / `action()` | 统一 SVG、触控尺寸、名称与焦点态 |
| 模态浮层 | `ConsoleMotion.openDialog()` / `closeDialog()` | 原生 dialog 语义、固定标题和唯一滚动内容区；复用 prepareDialog |
| 自定义日期 | `ConsoleControls.dateRangePicker()` | 当前绑定 run-date-* 节点；新增使用场景时先将节点绑定参数化，勿复制整套逻辑 |
| 内容进入 | `ConsoleMotion.reveal()` | 可中断、不叠加父子入场；轮询不重复播放 |
| 色彩 / 材质 | `glass.css` 语义变量 | 浅深主题共享结构，只变变量 |

## 4. 动效节奏

| 行为 | 现有参数 | 视觉要求 |
| --- | --- | --- |
| 按压 | 100ms | 及时确认触碰，轻微缩放 |
| 色彩反馈 / 退出 | 220ms | 保持连贯，不拖延操作 |
| 控件过渡 | 360ms | 清晰柔和 |
| 内容进入 / 翻月 | 520ms | 小幅移动、缓慢收束 |
| 弹窗进入 | 560ms | 16px 内平移，不夸张弹跳 |

主要运动曲线为 `cubic-bezier(.28,.72,.22,1)`，状态颜色使用 `cubic-bezier(.4,0,.2,1)`。CSS 的 `--ease` 与 JS 的 ease 必须同步。不能用 linear、统一 100ms 或 `transition:all` 代替层次化动效。

玻璃滑块使用现有近临界阻尼弹簧：settle stiffness 220 / damping 29，drag 600 / 44。拖动及时跟手，松手柔和归位。不要重写为固定时长的左右跳动。动画结束释放 requestAnimationFrame；快速反向操作必须连续。

尊重 prefers-reduced-motion：取消位移和弹性动画，保留状态变化、焦点及所有功能。不要通过动画延迟业务状态生效。

## 5. 日期范围行为

- 预设包含今天，使用浏览器本地日历日。筛选仍按对话开始时间；结束日包含全天，通过下一日零点的排他边界处理。
- 自定义弹窗打开时复制当前生效范围。只有确认才提交；关闭、Escape、遮罩点击不提交草稿。打开浮层不能把自定义误标为已生效。
- 第一次点日期设定开始并清空结束，第二次设定结束；倒序选择自动交换。再次点击可开始新范围。单日范围允许开始与结束相同。
- 范围用连续淡色带连接，两端用圆形主色标记。今天用小圆点表达；邻月日期弱化但仍可操作。
- 可直接输入 YYYY-MM-DD，支持远距离跨年；非法日期、闰日、倒置范围须校验并显示内联错误。不得重新引入浏览器原生 date 弹窗。
- 日历方向键按日 / 周移动，Home / End 到周首尾，PageUp / PageDown 翻月，Shift 配合翻年；Enter / Space 选择。日历采用单一 Tab 停靠点，关闭后返回触发按钮。

## 6. 响应式与验收

- 检查 360px、390px 手机宽度和桌面宽度；不允许横向溢出，日期输入不能挤坏栅格。短屏弹窗保留标题，内容区域可滚动，确认按钮可到达。
- 同时检查浅色、深色、键盘焦点、减少动态效果、减少透明度。颜色不作为唯一状态提示。
- 运行 `node --test chatai/monitor/*.test.cjs`；涉及 Go 内嵌资源时运行 `go test ./chatai/monitor`。
- 对交互改动实际操作：预设切换、自定义取消 / 确认、同日范围、跨月 / 跨年、倒序、无效日期、键盘导航、连续快速开关。保留有价值的回归测试，不写只检查样式字符串的测试。
- 本地预览可用模拟数据，但必须明确它不是生产数据验证。完成时说明测试结果和未验证部分。
